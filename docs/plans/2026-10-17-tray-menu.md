# Tray Context Menu

Add exactly three native context-menu items to the existing tray icon:

1. Open TapeOut Live: show the current panel without toggling it closed.
2. Current version: disabled, populated from Tauri package metadata for the installed build.
3. Quit TapeOut Live: exit the application through the framework lifecycle.

Keep left-click panel toggling and right-click menu activation separate. Translate menu labels using the saved interface language and update them when preferences change. Preserve panel dimensions and account data.

Delivery follows the existing local commit and installation workflow, retaining an application/profile backup before replacement. Native compilation and tests do not establish Windows device-level acceptance.
